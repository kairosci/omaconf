# quteconf

quteconf installs a native qutebrowser `config.py` for the Omarchy Qt browser. It retains qutebrowser's built-in navigation and keybindings while assigning familiar save, reload, tab and close shortcuts.

Install with `make qute` or `bash conf/qutebrowser/install.sh`. qutebrowser is retained as the QtWebEngine alternative to Brave. The private browser shortcut starts Brave in incognito mode.
