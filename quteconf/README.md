# quteconf

quteconf installs a native qutebrowser `config.py` for the Omarchy Qt browser. It retains qutebrowser's built-in navigation and keybindings while assigning familiar save, reload, tab and close shortcuts.

Install with `make qute` or `bash quteconf/install.sh`. The default browser hotkeys continue to use Omarchy's XDG browser selection. The private browser shortcut uses qutebrowser's temporary profile.
